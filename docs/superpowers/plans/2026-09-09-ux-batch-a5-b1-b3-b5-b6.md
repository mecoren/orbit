## 关键决策（已定，不再讨论）

- A5 **不做 redo**（YAGNI）；栈容量 30；Ctrl+Z 在焦点位于 input/textarea/contenteditable 时让位浏览器原生撤销。
- A5 撤销"完成" = patch 恢复 undone + **软删引擎克隆出的 next_instance**（恢复完成前状态；重复任务的提醒行不逆转，属可接受降级，07 行标注）。
- A5 覆盖面：完成/取消完成切换 + 全部批量操作（batch-actions 六函数）；删除已有既有撤销（use-undoable-delete）不动；详情抽屉单字段编辑不撤销（留后续）。
- A5 非 React 模块（task-actions/batch-actions）经 `shared/undo-bridge.ts` 模块级注册点入栈（Provider 挂载时注入），保证 node 测试不引 React。
- B1 表格六列：完成/标题/项目/标签/截止/优先级；不做列头点击排序、不做表内编辑；含多选批量（复制 list-view 选择语义，不重构 list-view 防回归）；j/k 键盘导航；manual 档不可拖（与看板口径一致）。
- B3 零依赖：不装 clipboard-manager 插件，DOM paste 事件直读 `clipboardData.files`；监听范围=详情抽屉附件区（错粘风险控制）。
- B5 complete action 放 actions 首位；前台（进程活着）= 经 BootGate 注入回调直调 `todoTaskComplete`；后台（进程被杀）= cancel 原通知 + 静默渠道横幅「已标记完成，打开应用后生效」，**不写 DB**（FRB 后台 isolate 不可重入，与 snooze 完全同构——DB 收敛由前台自然完成）；单后台入口改统一分发器（snooze/complete 二路）。
- B6 角标口径 = **今天截止或已逾期的未完成数**（dueDate < 今日24点 && !isDone，比纯"今天截止"更贴近"今天要做的"）；刷新三口 = todoTasksProvider listen（dbChanges 失效→重拉→listen）/ resumed 重算（跨零点）/ BootGate 注入完成后自动走第一口；真机厂商 ROM 验收遗留标注。

**核心代码（undo-stack.ts）：**

```ts
export interface UndoEntry {
  label: string;            // toast 文案实体，如「完成任务」
  count?: number;           // >1 时文案带条数
  undo: () => Promise<void>;
}

export type UndoOutcome =
  | { undone: true; entry: UndoEntry }
  | { undone: false; reason: "empty" }
  | { undone: false; reason: "failed"; entry: UndoEntry; error: unknown };

export interface UndoStack {
  push(entry: UndoEntry): void;
  undo(): Promise<UndoOutcome>;
  last: UndoEntry | null;
  clear(): void;
}

const MAX_ENTRIES = 30;

export function createUndoStack(): UndoStack {
  const entries: UndoEntry[] = [];
  return {
    push(entry) { entries.push(entry); if (entries.length > MAX_ENTRIES) entries.shift(); },
    async undo() {
      const entry = entries.pop();
      if (!entry) return { undone: false, reason: "empty" };
      try { await entry.undo(); return { undone: true, entry }; }
      catch (error) { return { undone: false, reason: "failed", entry, error }; }
    },
    get last() { return entries.length ? entries[entries.length - 1] : null; },
    clear() { entries.length = 0; },
  };
}

/** Ctrl+Z 判定（shift+ctrl+z = redo 语义，本产品无 redo 不命中） */
export function isUndoShortcut(e: { ctrlKey?: boolean; metaKey?: boolean; shiftKey?: boolean; key: string }): boolean {
  return (e.ctrlKey || e.metaKey) === true && e.shiftKey !== true && (e.key === "z" || e.key === "Z");
}

export function undoToastText(entry: UndoEntry): string {
  return entry.count && entry.count > 1 ? `已撤销：${entry.label} ${entry.count} 条` : `已撤销：${entry.label}`;
}
```

**undo-bridge.ts：**

```ts
import type { UndoEntry } from "./undo-stack";
type PushFn = (entry: UndoEntry | (() => UndoEntry)) => void;
let pusher: PushFn | null = null;
export function setUndoPusher(fn: PushFn | null): void { pusher = fn; }
export function pushUndo(entry: UndoEntry | (() => UndoEntry)): void { pusher?.(entry); }

**use-undo-stack.tsx 要点：** `useRef` 惰性建栈（onChanged → `setVersion(v+1)`）；context value = `{ push, canUndo, last, undo }`；`undo()` 取 `stack.last` 快照 → `stack.undo()` → ok 则 `qc.invalidateQueries()` + `toast.success(undoToastText(entry))`，failed 则 `toast.error('撤销失败，请手动检查')`；useEffect 挂 `setUndoPusher(api.push)`（cleanup 置 null）+ window keydown（`isUndoShortcut` + `document.activeElement` 非 INPUT/TEXTAREA/contentEditable 时 `preventDefault` 并 undo）。App.tsx ReadyShell：`<TooltipProvider><UndoStackProvider><RouterProvider/></UndoStackProvider><Toaster/></TooltipProvider>`（在 QueryClientProvider 内侧）。

const res = await todoTaskComplete(task.id);
pushUndo({
  label: "完成任务",
  undo: async () => {
    await todoTaskUpdate(task.id, { done: 0, done_at: null, status: "pending" });

/** 从 paste 事件提取第一个图片文件；截图位图无 name 时按时间戳生成 */
export function extractImageFromPaste(e: ClipboardEvent): { file: File; name: string; mime: string } | null {
  const files = e.clipboardData?.files;
  if (!files) return null;
  for (const f of Array.from(files)) {
    if (f.type.startsWith("image/")) return { file: f, name: f.name || pastedImageName(f.type), mime: f.type };
  }
  return null;
}
export function pastedImageName(mime: string, now = new Date()): string {
  const ext = mime === "image/jpeg" ? "jpg" : "png";
  const p = (n: number) => String(n).padStart(2, "0");
  return `粘贴图片_${now.getFullYear()}${p(now.getMonth() + 1)}${p(now.getDate())}_${p(now.getHours())}${p(now.getMinutes())}${p(now.getSeconds())}.${ext}`;
}
```

**hook 要点：** AttachmentsSection 内 useEffect 挂 window paste；焦点守卫（activeElement 为 INPUT/TEXTAREA/contentEditable 直接 return，让位原生粘贴）；命中图片 `preventDefault` → `file.arrayBuffer()` → `Array.from(new Uint8Array(...))` → `taskAttachmentAdd(taskId, name, mime, bytes)` → `qc.invalidateQueries(["task-attachments", taskId])` → toast「已粘贴附件「name」」；busy 守卫防连粘重复。附件区块底部常驻提示 `text-xs text-muted-foreground/60`：「支持 Ctrl+V 粘贴截图」。

**测试：** extractImageFromPaste（多文件取首个 image/*、纯文本 null、空 files null、无 clipboardData null、空 name 时间戳生成）、pastedImageName（格式/日期补零/jpeg→jpg/未知 mime→png）。

```dart
/// 今天截止或已逾期的未完成数（角标口径：比纯「今天截止」更贴近今天要做的）
int dueTodayOrOverdueCount(List<TodoTask> tasks) {
  final now = DateTime.now();
  final endOfToday = DateTime(now.year, now.month, now.day).millisecondsSinceEpoch + 86400000;
  return tasks.where((t) => !t.isDone && t.dueDate != null && t.dueDate! < endOfToday).length;
}
```
