## 八、问题与建议

1. **底栏「更多」hit test 失效（产品缺陷）**：干净重启后顶栏、列表、FAB 与底栏其余四个 tab 可点，唯「更多」整段无响应；`sendevent` 写 `/dev/input/event4` 与键盘 TAB/DPAD 遍历均不可达。本轮绕道「清单 → 页头设置」取证，建议排查 `HomeShell` 玻璃 Overlay 命中测试。
2. **S3 独立列举 403 已修复**：根因是列举工具用了 `quote(prefix, safe="/")` 保留斜杠、且优先 path-style；生产适配器 `infer_use_path_style` 对 `aliyuncs.com` 返回 false（虚拟主机风格），且 `build_canonical_query` 用 `urlencoding::encode` 把 `/` 编码成 `%2F`。按生产口径修正后（`s3_list_objects.py`）四个前缀列举全部成功（见第五节）。建议云端对象审计统一走生产适配器口径，不再维护两套签名。
3. **同步元数据 `version` 跨端不一致（建议修）**：删除发起端 `version=2`、pull 合并端 `version=1`。`version` 参与 LWW 同毫秒比较，虽本轮业务数据完全一致、后续更新会各自递增，但严格逐字段口径会报差异。建议二选一：引擎在 pull 合并时传播远端 `version`，或在一致性验收规范里明确剔除 `version` 等本地同步元数据。
4. **本地审计表不进同步白名单**：`sync_conflicts` 只在裁决端产生，属既定语义；验收口径应显式排除，避免误判为数据不一致。
5. **GUI 自动化解锁陷阱**：早期脚本每次 `force-stop` 重启会清内存 Data Key，且因滚动位置常找不到密码输入框，导致同步被 `not_unlocked` 静默跳过、账本不推进。改为「不重启 + 按需解锁 + 用 `sync_state.last_synced_at` 变化判定同步完成」后全部通过（`ensure_unlocked.py` / `robust_sync.py`）。建议把这套判据固化进 E2E 工具。
6. **误触防护**：脚本曾因模糊匹配弹出「清除本机同步密码缓存？」确认框（已取消、未执行）；已改为精确匹配并显式禁用断连/清理/重置类按钮。
7. **验收字段缺失**：`SyncState` 无 `downloaded_chunks`，建议补计数或修订验收文档；本轮用计数 + 桶指纹 + 前后账本比对替代。
8. **耗时**：S3 全量 push 33,211 ms（核心台）/ 145,891 ms（移动1 真机 GUI）；空库 pull 33,683 ms / 60,811 ms；真桌面壳 88,842 ms。建议补 10k/50k 档移动端 profile 基线。
