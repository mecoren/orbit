## 八、问题与建议

1. **真机 GUI 链路本轮未重跑（范围说明，非缺陷）**：11-12 / 11-13 的后续操作把两模拟器与桌面都重置成空库，`files/` 下已无 `sync_crypto_meta.json`、`sync_state.json`、`sync_configs`、`attachments/`，桌面也无 `sync_config.enc`。需求禁止「删除或修改同步密码」，在这些端上重建密码元数据会越过该边界，故本轮改走三实例测试台链路（生产引擎 + 真实 HTTP + 本地自建 WebDAV），它自建独立的密码元数据、不触碰任何既有同步配置。真机 GUI / 桌面 Tauri 壳的六项一致性结论见既有 run5 报告（三端 `all_equal=true`）。若需再跑真机链路，请先明确授权恢复三端密钥元数据的方式。
2. **旧证据库与当前 schema 不兼容（建议标注版本）**：run5 的 `seed5/orbit.db` 带已并入基线的 0002 迁移记录，直接复用会 `Migrate(VersionMissing(2))`。建议历史证据库随附 schema/migration 版本号，或统一改用 `seed_demo_db` 现生成（需求阶段 2 本就如此要求）。
3. **本机代理劫持回环地址（测试基建坑）**：`HTTP_PROXY=127.0.0.1:10063` 会让 `127.0.0.1:8123` 返回 502，且 Rust `reqwest` 同样读取该变量。建议把「启动前清除 6 个代理变量别名」固化进 E2E 启动脚本；探针统一用 `ProxyHandler({})`。
4. **解释器不一致**：Bash 默认 `python` 为 WorkBuddy 内置 3.14.3（无 cheroot / wsgidav），WsgiDAV 装在用户 Python 3.14。建议在 `dav_server.py` 启动说明里写死绝对路径。
5. **endpoint 随 IP 漂移**：原 secrets 写死 `192.168.31.108`，本机换 IP 后即失效。测试台在本机跑用 `127.0.0.1` 更稳；设备侧仍可用 `10.0.2.2` 或当前局域网 IP。
6. **`downloaded_chunks` 验收字段与实现不符**：建议补计数，或修订验收文档为 `pulled_modules` / `downloaded_attachments` + 桶指纹口径（与 run5 报告第 4 / 8 节同一问题，尚未修复）。
7. **吞吐不代表引擎基线**：WsgiDAV 是本地单进程 Python 服务，全量 push 51.6 s、空库 pull 54.1 s / 52.7 s；服务端性能不应读作同步引擎基线，建议单独建档。
8. **文件名口径**：需求指定 `2026-11-09`，实际执行为 2026-11-14，且该文件名已被 run5 报告占用。本轮用真实日期另存，未覆盖历史证据与 `docs/config-snapshot.json`。

## 九、结论

**一致。**

证据：`target/sync-e2e/run6/round-webdav/verification_phase4.json` 的 `all_pass=true` —— 三实例在 `plaintext_export_json` 双口径 11 表行数（阶段 4 冻结 214,110 行，含 799 墓碑，`exclude_deleted=true` 口径 tasks 39,201）、11 表全表规范化摘要与首/尾各 50 + 随机 100 条行级抽样、云端账本（`manifest_epoch=3`、11 表 523 桶、`remote_tables` 摘要 `45f5e3504c30e411`、`remote_tombstones` 摘要 `ea437cef6bb5ffb0`）、258 附件 sha256 集合（集合摘要 `c90626df4167a4e9`，含 2 个 8.5 MiB 分片文件）、回收站 799 条与 `deleted_at` 合计 `1433900898188618`、`stats_aggregate` 四年结果全部相等；`timeline.jsonl` 证明九步同步全程 `conflicts=0, errors=[]`、3.3 二次同步 0/0 零流量、3.6 / 3.8 双向改写回流可见；自建 WebDAV 的 PROPFIND 207 / 条件 PUT 201 / 重复 412 / 无鉴权 401 验证清单 CAS 与鉴权路径可用；云端 788 个对象与 `assets_parts` 2 个分片目录全部保留、未清理。

> 该「一致」结论的范围是**本轮三实例 × 生产引擎 × 真实 HTTP × 本地自建 WebDAV 链路**。阶段 5 按需求仅 S3 轮必做、本轮未执行；真机 GUI 链路本轮未重跑（原因见第八节 1），其结论另见 `docs/同步功能WebDAV端到端测试报告-2026-11-09.md`。
