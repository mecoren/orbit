## 三、进程模型与 IPC

```
┌────────────── React WebView（单份代码，响应式分叉）──────────────┐
│  desktop/ 分支：AppShell(TitleBar+Sidebar+CommandPalette)        │
│  mobile/  分支：栈式导航 Screen 组件                              │
└──────────────────────┬───────────────────────────────────────────┘
                       │ invoke() typed 包装（src/features/todo/api）
┌──────────────────────▼───────────────────────────────────────────┐
│ Tauri 2 Commands（src-tauri/commands）                            │
│  db_cmd: 初始化/加密打开/锁定      business_cmd: 44 个通用 CRUD   │
│  todo_cmd: 7 个复杂查询            crypto_cmd/sync_cmd: 安全与同步│
└──────────────────────┬───────────────────────────────────────────┘
                       │ State<AppState>{pool}
┌──────────────────────▼───────────────────────────────────────────┐
│ orbit_core（业务逻辑 100% 在此，命令层只做参数搬运）                │
└──────────────────────────────────────────────────────────────────┘
```

要点：
1. **全走 Tauri command 单通道**。wait-home 的 `mobile/rust_frbbindings`（FRB JSON-string 桥接约定）整体丢弃；`cloud_sync_api` 中为规避 FRB struct opaque 写的 `result_to_json` 类包装一并删除，直接返回结构体。
2. 事件下行统一 `app.emit()`：`db-change` / `sync_progress` / `todo_reminder:due`。
3. 命令签名语义必须保留：typed `UpdateInput` 的「缺省键 = 跳过更新」三态语义（serde `Option` + skip），前端依赖此语义做局部更新。

### 分发与更新（MVP 决策）

- MVP **不接入 tauri-plugin-updater**：自动更新需自建更新源并托管签名密钥，超出单人 MVP 维护成本；采用**手动下载覆盖安装**（NSIS / MSI / DMG / deb / AppImage 均自带升级语义）。
- M6+ 再评估 updater：届时更新清单拟托管 GitHub Releases（仓库 orbit），并一并启用公钥签名校验。

## 九、日志与遥测策略

| 项 | 决策 |
|---|---|
| 框架 | tauri-plugin-log：Rust 与前端 console 统一采集 |
| 输出目标 | 开发构建 → stdout；发布构建 → `{app_data_dir}/logs/`（单文件大小上限 + 保留最近 N 份的轮询） |
| 级别 | 发布默认 info；诊断场景经 `RUST_LOG` 环境变量临时提级，设置页日志入口记 M6+ |

**脱敏红线**（进代码评审清单）：日志禁止出现主密码、DB Key、同步密码、data_key 及其派生值、WebDAV/S3 完整凭据、同步包与备份包内容；仅允许表名、行数、fingerprint 前 8 位等元信息。

**遥测边界**：不接任何崩溃上报 / 使用统计 SDK——这是本地优先与 E2E 承诺的自然推论。崩溃现场仅落本地 `logs/crash.log`，由用户自行决定是否手动反馈。
