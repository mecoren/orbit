**待物理真机复核项**（4 项，均已在模拟器完成环境内最大化验证）：

- 2.3 的「软键盘面板避让」——MuMu 的 IME 帧高度为 0（外接键盘模式）；已验
  四输入框聚焦时 bounds 均在键盘上沿之上（含尝试停用 IME 触发真实面板：
  ROM 仅一个 IME 且无 LatinIME 回退，面板 Surface 只剩动画空壳——环境
  确证不可复现真实遮挡）；真机复验 IME inset 对表单抽屉/详情评论框的遮挡；
- 3.2 的「真机手感流畅度」——模拟器帧分析无卡顿（500 条 44fps 505 帧
  0 空白/0 跳变），真机 GPU 调度差异可能影响体感；
- 4.4 的「Doze 期间系统通知抑制」——模拟器 force-idle 下 0 系统通知
  （α 已知边界成立）、唤醒存活；真机待机一晚复测一次即可；
- 5.3 的「双端实机互推」——引擎语义已由 m4_sync_e2e E2E 全绿锁定（双实例
  收敛/墓碑/首同步 crypto/config 上传）。MuMu 上 app 内曾「reqwest 不发请求」
  经最小二进制分 uid 实验定性为 **release 缺 INTERNET 权限的产品 bug（已修复
  入包）**：shell uid 通 / app uid 被内核拦截，manifest 补声明后模拟器实测
  「测试连接」恢复（PROPFIND depth=1 真实发出）。剩余模拟器 UI 层问题
  （设置页「立即同步」按钮 onPressed 在 MuMu 不触发，涟漪可见——物理触摸
  不走模拟器事件注入，真机不受影响）仅影响本环境复验便利性。
  真机复核最小步骤：配置 WebDAV + 设同步密码 + 立即同步 + 第二设备同密码
  入环，约 2 分钟确认 bce1904 与 INTERNET 修复实机生效。
