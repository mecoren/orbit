# 05 UI 复刻规格 —— 移动端（Flutter → React/Tailwind）

> 蓝本：`wait-home/mobile/lib/modules/todo/*`。技术形态为 **React 重写**（Tauri 2 WebView），目标是观感与交互逐像素对齐 Flutter 版。

## 一、信息架构决策

| 链路 | 状态 | MVP 取舍 |
|---|---|---|
| `侧栏首屏 → 任务子列表 → 详情全屏` + `底部抽屉表单` | **已接线**，是现网实际 UX | ✅ 复刻基准 |
| `todo_list_page.dart` 完整单列表版（双行玻璃标题栏+视图选择器+搜索展开） | 未接线设计稿 | ⏸ 记 M6+ 增强 |

路由表（react-router，栈式导航语义）：

```
/todo                       侧栏首屏（快捷视图+项目）
/todo/tasks?view=|projectId=|ungrouped=1    任务子列表（三参数互斥）
/todo/:id                   详情全屏
新建/编辑：底部抽屉表单（非独立页；蓝本另有 todo_form_page.dart 不采用）
```

## 三、"液态玻璃"三件套（v2：白玻璃配方）

> **v2 改版（2026-09-20）**：旧配方 tint 仅 `alpha .15~.20`，玻璃近乎全透，
> 内容从标题栏下方穿过、文字浮在杂乱像素上，可读性差且显廉价。v2 采用
> **高不透明度白玻璃**：顶部接近实白、向下渐隐，既保留玻璃质感又保证清晰度。

任何玻璃表面必须同时具备：**① backdrop blur + ② 高不透明度 tint 底 + ③ 底部分隔线**，缺一即不成立。

| 使用处 | blur(σ≈CSS px 1:1) | tint | 底部分隔线 |
|---|---|---|---|
| LiquidGlassTitleBar | `blur(16px)` | surface@75%→0 垂直渐变 | 亮色极浅灰实线（`outline`）/ 暗色五段白微光 |
| GlassFab | `blur(14px)` | surface@82%（亮）/86%（暗）+ e2 阴影 | — |
| 表单日期字段盒 | `blur(10px)` | surface@50% | — |
| 卡片/弹层上限 blurStatic | ≤ `blur(45px)` | — | — |

分隔线：`height:1px` 水平渐变五段——亮色 `outline` `[0,.9,1,.9,0]`（白高光在浅底上不可见，
故 v2 亮色改用克制描边线定界）、暗色白色 `[0,.22,.32,.22,0]`。
无级渐变模糊（标题栏顶强底弱）：上层伪元素完整 blur+tint，用 `-webkit-mask-image` 垂直渐变做 alpha 遮罩；Safari/WKWebView mask 失效时降级为分段 blur + 渐变蒙版 div。**滚动 offset=0 时必须移除模糊层**（性能与观感双要求）。
性能纪律：滚动偏移存 ref 直接改 style.opacity，模糊层独立 memo 组件（对应蓝本 RepaintBoundary/ValueListenable 优化），禁止整页 setState。

## 四、逐屏规格

### 4.1 侧栏首屏 `/todo`

- 标题栏：LiquidGlassTitleBar 单行模式（showSecondRow=false），title "待办"，右侧 actions 仅搜索钮（Material Symbols `search_rounded`）→ push `/todo/tasks?view=all`。**左端云同步状态图标**（`sync_status_button.dart`，经 `LiquidGlassTitleBar.leading` 插槽：同步中转环 / 成功对勾回弹 1.8s / 失败红点常驻；移动端无 hover，点击弹底部信息面板 = 状态 + 上次同步 + 下次自动同步估算 + 失败原因 + 「立即同步」；未配置 / 未解锁 → push `/settings/sync`）。
- 主体 CustomScrollView 三段（**卡片化**，2026-09-26：与任务子列表 §4.2 同款 `OrbitCardSegment` 整卡口径——卡外缘左右各让 12，卡间 `cardGap`；首段圆上角 / 末段圆下角 / 段间 1px divider）：
  1. **快捷视图**：SectionHeader("快捷视图") + 7 个 ListTile 行共拼一张卡——leading icon size22 用 quickView 语义色、title 16/w500 onSurface、trailing `chevron_right_rounded`(onSurfaceVariant)。图标映射：全部任务 `list_alt_rounded` / 未完成 `radio_button_unchecked_rounded` / 已完成 `check_circle_outline_rounded` / 今天 `calendar_today_rounded` / 近7天 `date_range_rounded` / 收藏 `star_border_rounded`。点击 → `/todo/tasks?view=<name>`。
  2. **功能入口**：搜索 / 筛选器 / 回收站三行共拼一张卡（无分区头，与快捷卡各自成卡）；回收站行带计数 badge（回收站内任务数）。
  3. **项目**：SectionHeader("项目") + 项目行 + 「新建项目」行共拼一张卡，可拖拽重排（段位按卡内下标反算，新建行恒为末段）。行结构：12×12 圆角方块(hex_color||强调色) + 名称 16/w500 + 尾部[未完成计数 badge(surfaceContainerHighest 底、radius 8、padding h8/v2、字12，仅 >0 显示) + gap8 + `drag_handle_rounded`(onSurfaceVariant@50%)]；行内不再自带圆角（按压水波盖在卡面上，外缘圆角归卡片）。长按 = 项目操作抽屉（编辑 → push 编辑项目整页 §4.6 / 归档 / 删除保护流）；拖拽代理底色 surfaceContainerHighest。排序落库逐条 `sortOrder=i+1`，本地覆盖列表先行渲染，失败 toast"排序失败"(destructive)。
  4. **已归档**：有归档才渲染（SectionHeader("已归档") + 组卡，行尾恢复钮取消归档）。
  5. **未分组**：独立单段卡：`inbox_rounded`(22, onSurfaceVariant) + "未分组" 16/w500 + 同款计数 badge + chevron。
- 新建项目对话框：AlertDialog "新建项目" + WaitInputField(label 项目名称, autofocus) + 取消 TextButton / 创建 FilledButton；创建默认 `#3B82F6`；成功 toast"已创建/项目已创建"。
- 删除保护：有未完成任务 → 确认抽屉"无法删除"/"该项目下还有 N 条未完成任务，请先清空或移走任务后再删除。"/按钮"我知道了"（单按钮）；否则确认抽屉(destructive)"删除项目"/"确定要删除项目「x」吗？该操作不可撤销。"。**确认类交互（删除/清空/恢复/断开等）一律走 `showConfirmBottomSheet` 底部抽屉，不用 AlertDialog**（口径见 AGENTS.md；AlertDialog 仅保留带 TextField 的输入表单）。
- SectionHeader 规格：padding L16/R8/T12/B4，labelMedium、onSurfaceVariant、w600。
- 列表底部预留 space48。

### 4.2 任务子列表 `/todo/tasks`

- 页头（`OrbitPageHeader`：`surface` 实色 + 底边 1px `outline`）：返回 + 动态标题（项目名/"未分组"/视图名）+ 右上 **⋮ 顶部下拉面板**（`moreVertical` → `showOrbitDropdownPanel`，2026-09-23 二次改版）。面板两组八项，锚在页头下沿、不铺遮罩：
  1. 「这个列表」——编辑项目（仅项目视图出现，push §4.6）/ 视图（就地展开：列表视图 / 看板视图 / 表格视图，当前档打勾）/ 看板分组（仅看板档出现，就地展开：按项目 / 按状态）/ 隐藏已完成（开关项，勾 = 已完成卡收起，与卡头行同源同态）/ 显示详细（开关项，关 = 行内只剩标题 + 右列时刻的紧凑形态）/ 显示设置（底部抽屉：显示详细 + 所属清单 + 标签三开关，写即落盘；主关关闭时另两位置灰）；
  2. 「怎么操作」——筛选（行尾回显「已启用 N 项」，开既有筛选抽屉）/ 排序方式（就地展开五档）/ 批量选择（进多选态，先选上当前视图首条未完成任务）。
  展开子菜单期间其余顶层条目**置灰且不可选**（点它们只收起子菜单）；筛选生效时 ⋮ 挂计数角标（否则列表莫名变少没有出处）。多选态标题换「已选 N 项」+ 全选 / 退出两钮。
  宽度**定宽封顶 240px**（窄屏再按屏宽 62% 取小；参考竞品约占屏宽六成）——锚定面板不是弹层主体，不铺满；行高 `touchTarget(48)`，条目图标 22 + 文案 15，行尾可带补充文案 / 勾选 / 箭头。口径与动效见 §9.1/§9.2 与 `orbit_dropdown_panel.dart` 文件头。
- 列表（**卡片化**，2026-09-23）：`ListView` / `ReorderableListView` padding 四边 12（卡片外缘让位；看板 / 表格 / Logbook 仍满幅），每项 TodoTaskTile（§4.5）。整列未完成任务共拼**一张圆角白卡**（首段圆上角 / 末段圆下角 / 段间 1px divider），逾期区块头与「其余任务」分隔行同为卡内段；列表尾部另有**独立的「已完成 N ⌄」折叠卡**（见 §4.5 末）。重排档下已完成卡挂 `footer`，完成行不进可拖列表。
- 空态 EmptyState(icon=`checklist_outlined`)，文案按入口：暂无任务 / 暂无未完成任务 / 暂无已完成任务 / 今天没有截止的任务 / 本周没有截止的任务 / 暂无收藏任务 / 该项目暂无任务 / 暂无未分组任务。
- FAB：`OrbitFab`（**accentColor=全局 themeAccent**）右下悬浮，点击弹**底部快速添加面板**（携带 defaultProjectId 与 quickView，见 §十二）；长按从模板新建。空态「新建任务」同一入口。
- 过滤语义照抄：today=自然日相等；week=today ≤ d < today+7；勾选完成写 `status=pending|done`；星标写 `is_favorite`。

| 骨架呼吸 | 首屏初次加载（详情 / 统计 / 主列表 / 侧栏四处） | 明暗往返 1100ms（`skeletonPulse` × `breathe`） | 自绘 `OrbitSkeleton`（色取 `surfaceSecondary`）；**有旧值可守时不出现**，二级页与按钮内 loading 保留 spinner |

### 9.2 有意边界与取舍（未做项 + 已落地项的范围约束，非遗漏）

- **顶部下拉面板的就地展开不做高度动画**（2026-09-23）：展开 / 收起子菜单是**即时切换**
  （与系统菜单同感），避免与面板出场动画叠成「两段动画套娃」。展开期间其余顶层条目**置灰且不可点**
  （点它们只收起子菜单）——本面板没有「disabled 条目」态：上下文不适用的条目**按需不渲染**
  （编辑项目仅在项目视图、看板分组仅在看板档），而不是渲染成灰条点点看。
- **已完成折叠卡只覆盖列表两档**（标准列表 / manual 重排档，2026-09-23）：看板与表格没有承接位，
  维持改版前的隐藏口径（`filterTasks(hideDone: true)`）——完成历史混进卡片墙 / 表格会淹掉这两档的
  工作面板语义；Logbook（done 快捷视图）本身即完成集，不再叠一层折叠卡。卡内行**不播行入场 / 退场**
  （卡是 `Column` 而非懒加载列表），直显上限 20 条、其余走「查看全部」进 Logbook——上限是硬约束：
  无上限时展开会把万行完成历史一次性实例化。

- **行退场只覆盖标准列表分支**（2026-09-22 落地，原"不做行移除动画"的判断已推翻）：
  manual 重排档 / Logbook 分组档 / 看板 / 表格 / 多选态一律即时刷新（行组件与手势体系不同），
  只有标准列表这一支播退场。**延迟的只是主列表那次失效**（300ms，与退场等长），写库仍照常
  立即落库（ADR 0005 不延迟提交），其余缓存（详情 / 统计 / 回收站 / 搜索 / 标签）即时失效。
  可见面（行本体 + 逾期分组头）同帧保持旧值，不会出现"计数先减、行还在"；侧栏快捷视图计数
  与主列表同源 `todoTasksProvider`，因此也随行一起晚 300ms——代价仅"窗内返回侧栏闪一帧旧
  计数"，换来不把 ghost 状态扩散进聚合层。
- **行入场只覆盖标准列表分支**：manual 重排档（`ReorderableListView`）与 Logbook 分组档
  （done 视图）共用同一 `buildTile`，逐行追加入场需镜像数据源，回归面过大——二者维持即时切换。
- **manual 档长按独占给拖动，操作菜单由「原地松手」承接**（2026-09-22；位移判据 2026-09-23
  修正）：整行长按拾起拖动后，行内 InkWell 的长按必须置空（同按 500ms 时行内识别器先注册先赢），
  操作菜单改由 `onReorderStart` 记位 + `onReorderEnd` 时手指没动过（`Listener` 原始指针位移
  ≤ `kTouchSlop`）才兜回——菜单入口因此不必新增行内「更多」图标，行尾拖拽把手也一并移除。
  **判据不用列表回调**：`onReorderItem` 只在真正换过槽位时才触发（拖开一圈又落回原槽位全程无
  回调），且它与 `onReorderEnd` 的先后不由调用方掌握，用它置位移标记会把「拖动后松手」误判成
  长按、凭空弹出菜单。其余排序档 / 看板 / 表格无拖动语义，长按仍是菜单（多选入口在这些档位照旧）。
- **不做星标弹跳**：星标在本应用只经长按菜单切换（无原地点按入口），而列表条件渲染 +
  虚拟化复用无法区分"刚收藏"与"滚动入场"，"出现即弹跳"会在滚动中反复触发。
- **不做滑到底直接完成**与**全完成庆祝**：前者是手势语义变更（保留 `flutter_slidable` 面板式动作），
  后者属结构级新增。
- **抽屉入场不用过冲曲线**：全高抽屉过冲会在上移后露出屏幕底部空白，观感是错位而非弹跳。

## 十、可访问性与触达热区（2026-09-22）

- **操作按钮一律带读屏标签**：走 `IconButton.tooltip`（页头菜单/返回、信息行与表单日期行清除、
  搜索清除、侧栏设置、详情子任务 / 提醒 / 评论 / 附件 / 标签、表单保存）；行内色点用 Material
  `Tooltip` 包裹（标签行色点 = "更换颜色"）。**shadcn 弹层内容里改用 `sh.Tooltip`**——弹层挂在
  Navigator Overlay 之外，Material Tooltip 找不到 Overlay 祖先会抛断言（AGENTS.md"shadcn 弹层
  三坑"第 ③ 条）。
- **触达热区 48（`AppDimens.touchTarget`），视觉直径不变**：色点用外层 `Padding` 补白，视觉尺寸
  仍取原值——标签行色点 16（Padding 16）、标签色板抽屉 40（Padding 4）、新建标签对话框色板 36
  （Padding 6）、侧栏编辑项目对话框色板 32（Padding 8）、详情标签编辑弹层色板 26（Padding 11）。
  补白只加不缩，色板 `Wrap` 间距不动（视觉间隙因此略增，属有意）。
- **勾选框热区外扩（2026-09-25）**：`CircleCheckbox` 布局盒取 `max(size, 44)`、图形居中——22–28px
  图形热区在密集列表误触率高，外扩后可点面积达触控标准档而视觉直径不变；规格见 §七常量速查卡。

  （它返回整条祖先链，命中哪一层取决于遍历顺序，曾量到外层 640×56 的整行 Padding）；侧栏用例收尾

  定时器不会被本次 pump 跑掉）。

## 十一、底部抽屉与底部操作按钮（2026-09-22 收口）

- **骨架单一来源**：`shared/widgets/shadcn/orbit_sheet_scaffold.dart`——拖拽手柄（40×4）+ 标题
  （`title` 或自定义 `header`）+ **可滚内容区**（整屉高度上限，默认 0.85 屏高）+ **固定底部
  按钮行**（`OrbitSheetActions`）。新抽屉一律走骨架，不要再自写 `SafeArea + Column + 按钮行`。
- **按钮必须固定在滚动区之外**：确认 / 取消 / 保存类按钮放骨架尾栏，内容再长也不会把按钮顶出
  可视区；即点即关的选择型抽屉（单选 / 更多操作 / 视图模式）无尾栏。已按此改造：确认弹层、
  日期时间选择器、描述编辑、筛选器新建、模板新建/编辑、云同步面板、重复规则「确定」、
  列表过滤「清除全部筛选」（后两者的按钮原先在滚动区内，会随内容滚走）。
- **标签一律居中**：按钮被 `Expanded` 拉满宽时，shadcn 按钮内标签盒子与按钮同宽，默认
  `TextAlign.start` 会把字形顶到左边距（观感"字不在按钮中间"）——`OrbitSheetActions` 内已统一
  `TextAlign.center`，自绘尾栏时必须显式居中。按钮圆角/高度不变（`AppShapes.medium`／shadcn
  `radiusMd` = 14，实测绘制半径 14）。
- **形态**：双按钮（取消 outline 在左、确认 primary/destructive 在右）各占一半宽；单按钮
  （「立即同步」「清除全部筛选」）独占整行；键盘避让由骨架统一承担（底部内边距跟随 `viewInsets`）。
- **危险操作按钮必须实心**：`sh.Button.destructive` 常态填充取 **token 实色**
  （`destructive`）——shadcn 默认是 `destructive` 50% 透明 + 白字，落在浅色抽屉上就是淡粉，
  用户会读成「按钮被禁用」（2026-09-22 反馈）。悬停/按下混白 10% 变浅，禁用回落中性表面；
  与桌面 `bg-destructive text-white hover:bg-destructive/90` 同口径。覆盖点
  `core/theme/shadcn_theme.dart#buildDestructiveButtonTheme`（**全局**，包在 ShadcnLayer
  之内；测试壳 `test/support/orbit_test_app.dart` 同装配）。

## 十二、底部快速添加面板与「编辑操作」（2026-09-23）
