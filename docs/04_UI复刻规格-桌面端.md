# 04 UI 复刻规格 —— 桌面端

> 蓝本：`wait-home/desktop/src/modules/todo/*`（11 文件 ≈3470 行）+ 应用壳。本文为像素级复刻规格，标注 ⚖ 的条目是复刻时的**规范化决策**（偏离蓝本的唯一许可范围）。

## 一、复刻总则

1. 布局尺寸、间距、字阶、颜色值、交互时序**原样保留**，不做"顺手优化"。
2. 技术栈不变：Tailwind v4 CSS-first、Radix/shadcn 基元、@dnd-kit、cmdk、sonner。
3. 仅 §7 列出的 6 个不一致点允许偏离蓝本。
4. 所有文案中文原样照抄。

## 三、组件规格

### 3.1 ProjectSidebar（w-56）

```
<div class="flex h-full w-56 flex-col overflow-y-auto border-r border-border bg-card/30">  ← 整栏统一滚动（⚖⑥）
├─ 视图头："视图"(text-xs uppercase muted) + 折叠钮 PanelLeftClose(h-6 w-6)
├─ 快捷入口区 p-3 > space-y-1；按钮 rounded-md px-3 py-2 text-sm
│    active: bg-primary/10 text-primary font-medium；icon size=16 用各自语义色：
│    全部任务 ListTodo #3B82F6 · 未完成 CircleDot #F59E0B · 已完成 CheckCircle2 #22C55E
│    今天 CalendarDays #EF4444 · 近7天 CalendarRange #F59E0B · 收藏 Star #8B5CF6

├─ 筛选器组（有保存的筛选器才渲染）
└─ 项目列表区 px-3 pb-3（不带 flex-1/独立滚动，随整栏滚动）

        + Folder 图标按项目色染色(h-4 w-4, hex_color || #3B82F6)；未分组行用 Inbox 图标；
          行 paddingLeft 12+depth×14，图标/文字列与快捷视图区对齐（left 24 / 48）
        + 项目名 truncate；active: bg-primary/10 text-primary；未完成计数（0 不占位）
          排在待回顾琥珀点与折叠箭头左侧，折叠箭头钉行尾最右（仅父节点，叶子行零占位）；
```

- 拖完本地 arraymove，再逐条 `todoProjectUpdateSortOrder(id, i+1)` 重编号 1..N。
- **未分组为虚拟固定项**（id=-1），位置存 localStorage `todo_sidebar_ungrouped_after`（记录位于哪个真实项目之后）。
- 删除保护：项目下有未完成任务 → "无法删除" AlertDialog；无任务 → "删除项目"确认 AlertDialog。

### 3.2 任务行 TaskListView

容器 `flex-1 overflow-y-auto`；空态居中 "暂无任务"（text-sm muted）。行分隔线：虚拟化行是绝对定位的兄弟，`divide-y` 不生效，改**每行自带 `border-b`**。每行为 ContextMenu 包裹的 `group flex items-center gap-3 px-4 py-3 hover:bg-accent/30`：

> **列表三态与逾期置顶段（2026-09-18 口径）**：主列表查询不挂 `placeholderData`（大列表缓存
> `gcTime: 10_000`），故**换视图/换项目的瞬间首帧走骨架**（Skeleton/ErrorState/EmptyState 三态
> 承接），不再保留上一视图的旧万行数组——闪烁是有意取舍，实测一份万行结果集只值 2MB，
> 换取的是「按谓词分叉的驻留不再长期挂着」（归因见 `docs/09` §四）。
> **列表平铺（2026-10-29 撤回日期分节）**：原「已逾期 / 今天 / 以后 / 无日期 / 已完成」五节
> 分类头与左侧快捷视图重复，已撤掉四档；列表回到「逾期处置条 + 平铺任务」两段——
> **非 manual 排序档**：逾期集置顶（33px 处置条：箭头 + 红色「已逾期」+ 计数 + 「顺延」下拉，
> **整行点击即折叠/展开**，折叠态持久化 `todo_section_collapsed` 的 `overdue` 项），
> 其余任务按排序档平铺、已完成（done=1 或 status=done）整段沉尾，逾期行不给拖拽把手；
> **manual（拖拽顺序）档**：逾期与已完成的抽段/沉尾全部取消，顺序即 position 序（拖到哪就是哪），
> 逾期行同样给拖拽把手、不再置顶，处置条降级为「只读总览 + 顺延」（不可折叠，计数取壳层全局逾期集）。
> 两种档位下逾期行元信息首位都带 `已逾期` 红色胶囊徽标。处置条与任务行合成**同一条虚拟流**
> （`rows` 内 `s-overdue` / `t-<id>` 两种键）；点击/勾选/键盘 j-k 仍只走可见任务序列
> （`stream`，置顶档折叠时逾期行不参与）。旧「逾期置顶段裸渲染」曾把 DOM 节点抬到近万，
> 平铺沿用同一条虚拟流口径。

| 元素 | 规格 |
|---|---|
| 完成 checkbox | `h-5 w-5 rounded-[4px] border-2` 方角（移动端同源）；done：`border-muted-foreground bg-muted-foreground`+白勾 SVG（弱化灰实底，与移动端 `OrbitCheckbox` 的 `deactivatedText` 同口径，不再保留待办蓝）；未完成：`border-muted-foreground/30 hover:border-primary`，**描边另由优先级色覆盖**（P0「无」回落中性灰）。**仅多选态在同一位置改渲染多选框**（`rounded-[4px] border`，选中 `border-primary bg-primary`），行首不再额外渲染第二个勾选框 |
| 优先级竖条 | 列表视图**仅多选态渲染**：行左缘 `absolute inset-y-1.5 left-0 w-1 rounded-full` PRIORITY_COLOR（六档全显，P0「无」浅灰 #D1D5DB 也渲染）——默认态优先级在完成框描边上（同一信息不上两处颜色），多选态完成框变多选框后才移到竖条。表格视图行左缘竖条常显 |
| 标题 | `text-[15px] leading-5`；done 时 muted + line-through |
| 元信息行 | `text-xs muted`：标签条目(左色点 `size-1.5 rounded-full` hex_color + 右标签名 text-[10px] muted，超 3 折叠 +N) · 项目名 · Clock(size=11)+截止时间；**逾期且未完成整段 `text-red-500`** |
| 截止文案 | ±15 天内 `formatDistanceToNow(zhCN)`，否则 `MM-dd` |
| 星标 | Star size=16；激活 `fill-yellow-400 text-yellow-400`；未激活 `opacity-0 group-hover:opacity-100` |

### 3.3 看板 KanbanView

- 容器：`DndContext(PointerSensor distance:5, pointerWithin)` 内 `flex h-full gap-4 p-4`；非拖拽 `overflow-x-auto`，拖拽中 `overflow-x-hidden`。
- 分列（工具栏 Select 控制）：`project` 按 project_id（无项目归"未分组"，列序按 key localeCompare）/ `status` 固定 pending→doing→done。项目列头色恒 `#3B82F6`；状态列用 STATUS_COLOR。
- 列 `w-72 shrink-0 rounded-lg border-border/50 bg-muted/20`；isOver 时 `border-primary/40 bg-muted/40`。列头 `border-b px-3 py-2`：圆点(h-2 w-2)+标题(text-sm font-medium)+数量(text-xs muted)。卡片区 `space-y-2 overflow-y-auto p-2`；空列 h-20 居中"拖拽任务到此处"(muted/40)。
- 卡片（同时挂 useDraggable+useDroppable）：`relative rounded-md border-border/50 bg-card p-3 shadow-sm hover:shadow-md`；拖拽中 opacity-40；作为落点 `ring-2 ring-primary/40`；transform 过渡 `160ms cubic-bezier(0.25,1,0.5,1)`。内容两块：①**标题行**——勾选框（完成/多选共用同一位置，2026-10-30）+ 标题(text-sm font-medium，done 划线) + 星标；②**元信息单行**（与标题左缘对齐，可换行）——标签条目(max 2，同 3.2 口径) · Calendar(size=11)+MM-dd · 提醒徽标 · percent_done%，`text-xs muted`，**逾期且未完成整段 `text-destructive`**。优先级统一由勾选框描边承载（P0 回落中性灰）；多选态勾选框变多选框后，改由卡片左缘 `absolute inset-y-2 left-0 w-1 rounded-full` 竖条承载（与 3.2 列表行同口径）。**不做顶部通栏优先级色条**（悬在标题上方只剩一道孤线），**不显示子任务进度条**。
- DragOverlay：dropAnimation=null，同卡片结构 + `border-primary/40 shadow-xl`。
- **拖拽语义**：同列落到卡片上→插到目标前 `onTaskReorder(taskId, prevId, targetId)`；同列空白→追加 `(taskId, lastId, null)`；异列→先 `onTaskMove(taskId, groupKey)` 改 project_id 或 status/done/done_at，再 `onTaskReorder(taskId, null, targetId)`。position 写入 `todo_tasks_update_position`。

### 3.4 详情抽屉 TaskDetailDrawer

`SheetContent class="flex w-full max-w-xl flex-col gap-0 p-0 sm:max-w-xl"`——**头部固定 + 内容区独立滚动**（标题行常驻不随内容滚走）：标题行包 `shrink-0 px-6 pt-8`，其余区块包 `min-h-0 flex-1 overflow-y-auto > flex flex-col gap-4 px-6 pb-8 pt-4`。区块顺序：

1. **标题行**（固定头部；border-b pb-4）：圆环 checkbox（同 3.2）+ 行内编辑标题（h2 text-xl font-semibold，点击变 Input，Enter 存/Esc 还原）+ Star / Trash2 ghost(h-8 w-8)。
2. **属性网格**：`rounded-xl bg-muted/40 p-3.5 grid grid-cols-2 gap-x-6 gap-y-3 text-sm`；InfoRow = icon(14 muted)+label(text-[13px] muted)+value(truncate font-medium，点击 Popover 即改即存)：优先级 Flag(Popover w-36 六档带色点)/状态(w-32 色点带 ring-2 ring-offset-1)/项目 FolderOpen(w-56 含"未分组")/截止日期(Popover **w-72**：快捷菜单 ⇄ 日历+内联时间数字输入行+清除/取消/确定——不内嵌 DateTimePicker，Popover 套 Popover 布局异常)/开始日期 CircleStop(Popover w-64：QuickDateMenu kind=date 快捷项 ⇄ 纯日历，**无时分行**——start_date 为日期级零点语义，显示 yyyy-MM-dd，与移动端详情「截止→开始」相邻同款)/完成进度(percent_done>0 显示 %，占位 div 保持对齐)/完成时间(done_at 非空显示 yyyy-MM-dd HH:mm，未完成为空占位)/重复。
3. **描述**：SectionBlock(AlignLeft) 恒渲染——展示态 `whitespace-pre-wrap text-[13px]`，点击进入行内编辑（Textarea 自适应高度，Ctrl/Cmd+Enter 保存、Esc 取消、失焦兜底保存，trim 空写 null 清空；角标显示 `N/5000`）；空描述显示"+ 添加描述"占位按钮。
4. **子任务**：SectionBlock(ListChecks)+badge 完成数/总数(rounded-full bg-muted)→ SubtaskList（方形 checkbox+标题 span truncate **带原生 title 悬浮提示**（超长标题 hover 可读全文，与日历节假日/关联行同款原生 title 惯例）+hover 删除+内联添加框）。
5. **标签**：SectionBlock(Tag)→ LabelAdder：已挂条目 `rounded-md border px-2 py-0.5 text-xs muted`（色点 `size-2 rounded-full` hex_color + 标签名 + X 移除，与列表行 LabelChips 同形制）；"添加标签"outline(h-7)→Popover(w-64)：checkbox 多选(max-h-60 滚动)+底部 border-t 新建输入(Enter 创建，随机取 8 色)。
6. **提醒**：SectionBlock(Clock)：每条 `group rounded-lg bg-muted/40 px-3 py-2 text-[13px]`(Bell+时间，点击弹 DateTimePicker 编辑=删旧建新；hover 显 X)+"添加提醒"文字按钮。
7. **关联任务**：SectionBlock(Link2)，relations.length>0 才渲染；徽章 `bg-accent text-[11px]` 关系类型（子任务/阻塞/被阻塞/关联/重复于/重复项）+ "任务 #{other_task_id}"。
8. **评论**：CommentList 卡片+相对时间+hover 删除+底部「添加评论」占位框（点击就地展开固定高度输入区，内容超出内部滚动；Ctrl+Enter 发送 / Esc 取消 / 取消钮收起）。

数据流：打开时 `todoTaskGetDetail(id)` 五合一详情；每次变更后 loadDetail()+onTaskChanged()（父级 refetch）；删除走 useConfirmDelete(entityLabel="待办"，文案："删除待办"/"确定要删除「xxx」吗？此操作无法撤销。")。

### 3.6 新增抽屉 TaskCreateDrawer（详情形态，2026-10-22）

`SheetContent class="flex w-full max-w-xl flex-col gap-0 p-0 sm:max-w-xl"`——与 3.4 详情抽屉同宽、同一套字段语言（`InfoRow` / `SectionBlock` / 三个受控日期与重复编辑器直接从详情模块复用），差别只在**数据模式是草稿**：所有字段只写本地 state，点「创建」一次性落库。

- **标题行**（`shrink-0 border-b px-6 pt-8 pb-4`）：静态圆环占位（h-5 w-5，未落库不可勾选）+ 常驻 `Input`（h-8、border-0、text-xl font-semibold、placeholder「准备做什么？」、打开自动聚焦）+ 下方 `text-[11px] muted` 说明「填写标题即可创建；日期、标签等其余字段可按需补充」。Enter 直接创建（IME 组合期不提交）。
- **属性网格**：与 3.4 同款 `rounded-xl bg-muted/40 p-3.5 grid grid-cols-2 gap-x-6 gap-y-3 text-sm`，7 格：优先级 / 状态 / 项目 / 截止日期 / 开始日期 / 预计时长（NumberInput h-6 w-20 + 「分钟」后缀，空态 placeholder「未设置」）/ 重复。**进度与完成时间不渲染**（新建态无意义）；**预计时长在详情是只读，新建态必须可填**（否则创建后无录入入口）。
- **空值提示**（本次核心诉求）：未填的开始/截止日期用虚线胶囊 `border-dashed border-muted-foreground/40 text-muted-foreground` + 文案「+ 设置」，与真值的实心 `font-medium` 拉开层级；详情沿用「设置」不做虚化（详情是已填真值的语境）。
- **区块**：描述（空态「+ 添加描述」，点击展开 Textarea，Ctrl+Enter 完成 / Esc 收起，角标 N/5000）/ 子任务（草稿标题列表 + 「添加子任务」输入行，方框为静态占位——未落库无法勾选）/ 标签（已选 chips + 「添加标签」Popover，多选与就地新建，Enter 添加）/ **提醒**（空态 trailing 主色「+ 添加提醒」；展开 `DateTimePicker` + 「持续提醒（响到完成为止）」`Switch`，确定后成行 `Bell + yyyy-MM-dd HH:mm`，持续态带橙色「持续」chip 可点关闭，hover 显 X 删除；新建态单条）。关联、评论、附件、历史留到创建后进详情补充（id 驱动的即改即存，草稿化成本高于收益；提醒不在此列——「设个提醒再建」是常见动作）。

## 四、筛选 / 排序 / 搜索语义

- 搜索：匹配 title + description，不区分大小写。**关键词走服务端**（防抖 200ms 后单开一路
  `["todo_tasks", keyword, 谓词]` 查询，SQL `LIKE` 按 title+description 过滤且命中集保留全列）：
  万行全量通道按批2 列裁剪以 `NULL AS description` 占位不传输（省 47% IPC 体积），客户端拿不到
  描述文本，故不能只靠本地过滤——此前恒传 `keyword:""` 导致**搜描述静默无结果**（2026-09-19 修）。
  全量通道刻意不随关键词收窄：侧栏各项目未完成计数与详情导航吃的是它。
- 状态筛选（2026-10-28 对齐 TickTick 改**多选**）：待办 / 进行中 / 已完成任意并集（档间为「或」），
  空集 = 全部状态（菜单「全部状态」一键清空）；「未完成」= 待办 + 进行中两选（派生档不落集合）。
  下推口径：单档且非 done 仍走 `status` 等值（与旧路径逐字一致），其余交 `status_in` 集合；
  判定用派生状态（脏 status 回落 pending，与看板 status 列同源），`done` 档兼容 `done=1` 老数据。
  保存筛选器条件 JSON 的 `status` 是等值键：仅单档且非「未完成」时固化，多档丢弃（对话框提示）。
- 列表平铺：逾期 = 截止早于 now 且未完成（与行内红字同源，不用今日零点）；
  非 manual 档逾期行置顶且不给拖拽把手、已完成（done=1 或 status=done）整段沉尾；
  manual（拖拽顺序）档不抽段不沉尾，顺序即 position 序、逾期行同样可拖（2026-10-29）。
- 优先级筛选：all / 0..5 精确等于。
- 快捷视图：all / undone / done / today(due_date 在今日 0 点起 24h) / week(未来 7 天) / favorite(is_favorite==1)。
- 数据范围：项目精确 / 未分组(project_id IS NULL) / 隐藏 is_deleted==1（计数同样排除）。
- 排序（#26 双端档位，「↑↓」菜单，localStorage `todo_sort_key` 持久化）：`manual`(position 升序→created_at 降序，唯一允许拖拽重排的档位——列表行/看板卡拖拽、看板同列落位均仅该档生效)/`due`(无截止垫底→时间升序)/`start`(2026-10-29 新增，与 due 同构：无开始垫底→开始时间升序，分页下推 `sort_key=start` 走 `idx_todo_tasks_keyset_start`)/`priority`(大者前)/`title`(zh-Hans-CN)/`created`(降序)。**方向档**（2026-09-29 工具栏收拢新增）：`todo_sort_dir` 存 `asc`/`desc`（未存过 = null = 各档现状默认方向，存量顺序零变化）；方向只翻转主键比较，回落键不翻、due/start 档无值恒沉底、manual 档忽略方向；各档默认方向 `BASE_SORT_DIR = { due: asc, start: asc, priority: desc, title: asc, created: desc }`。**三视图归一**：sortTasks 结果直接决定列表序、看板列内序、日历按日分组内序（视图不再自行按 position 重排覆盖）；看板跨列移动（改归属）任何档位可用，落位走 position 中值。前端内存排序，一次拉取 `TASK_LIST_PAGE_SIZE`（=10000）条——**不是全量**，命中上限时工具栏下方出条幅明确告知列表不完整（§二 骨架图）。
