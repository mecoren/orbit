## 三、进程模型与 IPC（ADR 0003 双通道）

```
┌─────────── 桌面：React WebView（apps/desktop/src）───────────┐
└──────────────────────┬───────────────────────────────────────┘
                       │ invoke() typed 包装（lib/tauri.ts）
┌──────────────────────▼───────────────────────────────────────┐
│ Tauri 2 Commands（apps/desktop/src-tauri/commands）           │
└──────────────────────┬───────────────────────────────────────┘
                       │
┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┴ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
│                    orbit_core（业务逻辑 100%）                  │
└─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┬ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
                       │ orbit-flutter（FRB api 面一一对应）
┌──────────────────────▼───────────────────────────────────────┐
│ Flutter（apps/mobile/lib，Riverpod + go_router）               │
│  事件：EVENT_BUS → StreamSink（db-change / sync-finished /    │
│  todo_reminder:due 20s 轮询守护在桥内启动）                     │
└──────────────────────────────────────────────────────────────┘
```

要点：
1. **双通道桥接**（ADR 0003）：桌面全走 Tauri command；移动走 `crates/orbit-flutter` FRB 桥，api 与桌面命令一一对应，显式 DTO 镜像（防 opaque 退化），update 同走 patch JSON 三态语义。
2. 事件下行：桌面统一 `app.emit()`；移动由 EVENT_BUS 转 StreamSink（`db-change` / `sync-finished` / `todo_reminder:due`）。
3. 命令签名语义必须保留：typed `UpdateInput` 的「缺省键 = 跳过更新」三态语义（serde `Option` + skip），前端依赖此语义做局部更新。

### 分发与更新（MVP 决策）

- MVP **不接入自动更新**（桌面 tauri-plugin-updater / Android Play 渠道均超出单人维护成本）；
  采用**手动下载覆盖安装**（NSIS / MSI / DMG / deb / AppImage 均自带升级语义；
  Android 直接覆盖安装 `cn.wait.orbit`，同 applicationId 签名一致即可）。
- M6+ 再评估 updater：届时更新清单拟托管 GitHub Releases（仓库 orbit），
  并一并启用公钥签名校验。

## 九、日志与遥测策略

| 项 | 决策 |
|---|---|
| 框架 | tauri-plugin-log：Rust 与前端 console 统一采集 |
| 输出目标 | 开发构建 → stdout；发布构建 → `{app_data_dir}/logs/`（单文件大小上限 + 保留最近 N 份的轮询） |
| 级别 | 发布默认 info；诊断场景经 `RUST_LOG` 环境变量临时提级，设置页日志入口记 M6+ |

**脱敏红线**（进代码评审清单）：日志禁止出现主密码、DB Key、同步密码、data_key 及其派生值、WebDAV/S3 完整凭据、同步包与备份包内容；仅允许表名、行数、fingerprint 前 8 位等元信息。

**遥测边界**：不接任何崩溃上报 / 使用统计 SDK——这是本地优先与 E2E 承诺的自然推论。崩溃现场仅落本地 `logs/crash.log`，由用户自行决定是否手动反馈。
