# 04 UI 复刻规格 —— 桌面端

> 蓝本：`wait-home/desktop/src/modules/todo/*`（11 文件 ≈3470 行）+ 应用壳。本文为像素级复刻规格，标注 ⚖ 的条目是复刻时的**规范化决策**（偏离蓝本的唯一许可范围）。

## 一、复刻总则

1. 布局尺寸、间距、字阶、颜色值、交互时序**原样保留**，不做"顺手优化"。
2. 技术栈不变：Tailwind v4 CSS-first、Radix/shadcn 基元、@dnd-kit、cmdk、sonner。
3. 仅 §7 列出的 5 个不一致点允许偏离蓝本。
4. 所有文案中文原样照抄。

## 二、页面骨架与选中态

```
<div class="flex h-full overflow-hidden">
├─ ProjectSidebar                     ← 左栏 w-56，border-r，bg-card/30
├─ <div class="flex flex-1 flex-col overflow-hidden">   ← 中栏
│   ├─ 工具栏：flex items-center justify-between gap-3 border-b px-4 py-3
│   │    左：<h1 text-lg font-semibold>标题</h1> + <span text-sm muted>数量</span>
│   │    右：Search Input(h-8 w-40 pl-8) · 状态 Select(w-28) · 优先级 Select(w-28)
│   │        · 视图切换双联钮(ListTodo/LayoutGrid size=14, secondary, rounded-r/l-none)
│   │        · [看板模式]分组 Select(w-24) · 标签管理(h-8 w-8 Tag icon) · 新增按钮(Plus size=14+"新增")
│   ├─ 内容区：loading ? 加载中 : kanban ? <KanbanView> : <TaskListView>

```

**选中态三选一互斥**：`selectedProjectId`(null) × `selectedQuickView`(null) × `selectedUngrouped`(bool)。标题映射：未分组 / 项目名 / 未完成 / 已完成 / 今天截止 / 本周截止 / 收藏 / 全部任务。

视图切换状态持久化 localStorage `todo_view_mode`，进页自动还原。

## 三、组件规格

### 3.1 ProjectSidebar（w-56）

```

├─ 快捷入口区 p-3 > space-y-1；按钮 rounded-md px-3 py-2 text-sm

│    今天截止 CalendarDays #EF4444 · 本周截止 CalendarRange #F59E0B · 收藏 Star #8B5CF6
└─ 项目列表区 flex-1 overflow-y-auto px-3 pb-3
     ├─ 头："项目"(text-xs uppercase muted) + Plus(h-6 w-6)
     ├─ 新增态：Input(h-8 autoFocus; Enter 创建 / Esc 取消)
     └─ DndContext(closestCenter) SortableContext(verticalListSortingStrategy) 每行：
          GripVertical 手柄(w-3 cursor-grab muted/30)
        + 颜色方块 h-2.5 w-2.5 rounded-sm(hex_color || #3B82F6)；未分组行用 Inbox 图标
```

- 拖完本地 arraymove，再逐条 `todoProjectUpdateSortOrder(id, i+1)` 重编号 1..N。

- 删除保护：项目下有未完成任务 → "无法删除" AlertDialog；无任务 → "删除项目"确认 AlertDialog。

### 3.2 任务行 TaskListView

容器 `flex-1 overflow-y-auto divide-y divide-border/30`；空态居中 "暂无任务"（text-sm muted）。每行为 ContextMenu 包裹的 `group flex items-center gap-3 px-4 py-3 hover:bg-accent/30`：

| 元素 | 规格 |
|---|---|
| 完成 checkbox | `h-5 w-5 rounded-full border-2` 圆环；done：`border-primary bg-primary`+白勾 SVG；未完成：`border-muted-foreground/30 hover:border-primary` |
| 优先级竖条 | 行左缘 `absolute inset-y-1.5 left-0 w-1 rounded-full` PRIORITY_COLOR（P1–P5）；**P0 不渲染**（与移动端列表/详情抽屉口径一致） |
| 标题 | `text-[15px] leading-5`；done 时 muted + line-through |
| 元信息行 | `text-xs muted`：标签条目(左色点 `size-1.5 rounded-full` hex_color + 右标签名 text-[10px] muted，超 3 折叠 +N) · 项目名 · Clock(size=11)+截止时间；**逾期且未完成整段 `text-red-500`** |
| 截止文案 | ±15 天内 `formatDistanceToNow(zhCN)`，否则 `MM-dd` |
| 星标 | Star size=16；激活 `fill-yellow-400 text-yellow-400`；未激活 `opacity-0 group-hover:opacity-100` |

### 3.3 看板 KanbanView

- 容器：`DndContext(PointerSensor distance:5, pointerWithin)` 内 `flex h-full gap-4 p-4`；非拖拽 `overflow-x-auto`，拖拽中 `overflow-x-hidden`。
- 分列（工具栏 Select 控制）：`project` 按 project_id（无项目归"未分组"，列序按 key localeCompare）/ `status` 固定 pending→doing→done。项目列头色恒 `#3B82F6`；状态列用 STATUS_COLOR。
- 列 `w-72 shrink-0 rounded-lg border-border/50 bg-muted/20`；isOver 时 `border-primary/40 bg-muted/40`。列头 `border-b px-3 py-2`：圆点(h-2 w-2)+标题(text-sm font-medium)+数量(text-xs muted)。卡片区 `space-y-2 overflow-y-auto p-2`；空列 h-20 居中"拖拽任务到此处"(muted/40)。
- 卡片（同时挂 useDraggable+useDroppable）：`rounded-md border-border/50 bg-card p-3 shadow-sm hover:shadow-md`；拖拽中 opacity-40；作为落点 `ring-2 ring-primary/40`；transform 过渡 `160ms cubic-bezier(0.25,1,0.5,1)`。内容自上而下：优先级条(P1–P5 `h-0.5 rounded-full` PRIORITY_COLOR；P0 透明占位保持卡片高度一致)→ Check(done)+标题(text-sm font-medium, done 划线)+星标 → 底部 text-xs：Calendar(size=10)+MM-dd、percent_done%。**不显示标签/子任务进度**。
- DragOverlay：dropAnimation=null，同卡片结构 + `border-primary/40 shadow-xl`。
- **拖拽语义**：同列落到卡片上→插到目标前 `onTaskReorder(taskId, prevId, targetId)`；同列空白→追加 `(taskId, lastId, null)`；异列→先 `onTaskMove(taskId, groupKey)` 改 project_id 或 status/done/done_at，再 `onTaskReorder(taskId, null, targetId)`。position 写入 `todo_tasks_update_position`。

### 3.4 详情抽屉 TaskDetailDrawer

`SheetContent class="w-full max-w-xl overflow-y-auto sm:max-w-xl"`，内容 `flex flex-col gap-4 px-6 pb-8`。区块顺序：

1. **标题行**（border-b pb-4）：圆环 checkbox（同 3.2）+ 行内编辑标题（h2 text-xl font-semibold，点击变 Input，Enter 存/Esc 还原）+ Star / Trash2 ghost(h-8 w-8)。
2. **属性网格**：`rounded-xl bg-muted/40 p-3.5 grid grid-cols-2 gap-x-6 gap-y-3 text-sm`；InfoRow = icon(14 muted)+label(text-[13px] muted)+value(truncate font-medium，点击 Popover 即改即存)：优先级 Flag(Popover w-36 六档带色点)/状态(w-32 色点带 ring-2 ring-offset-1)/项目 FolderOpen(w-56 含"未分组")/截止日期(Popover **w-72**：快捷菜单 ⇄ 日历+内联时间数字输入行+清除/取消/确定——不内嵌 DateTimePicker，Popover 套 Popover 布局异常)/完成进度(percent_done>0 显示 %，占位 div 保持对齐)。
3. **描述**：SectionBlock(AlignLeft) 恒渲染——展示态 `whitespace-pre-wrap text-[13px]`，点击进入行内编辑（Textarea 自适应高度，Ctrl/Cmd+Enter 保存、Esc 取消、失焦兜底保存，trim 空写 null 清空；角标显示 `N/5000`）；空描述显示"+ 添加描述"占位按钮。
4. **子任务**：SectionBlock(ListChecks)+badge 完成数/总数(rounded-full bg-muted)→ SubtaskList（方形 checkbox+标题+hover 删除+内联添加框）。
5. **标签**：SectionBlock(Tag)→ LabelAdder：已挂条目 `rounded-md border px-2 py-0.5 text-xs muted`（色点 `size-2 rounded-full` hex_color + 标签名 + X 移除，与列表行 LabelChips 同形制）；"添加标签"outline(h-7)→Popover(w-64)：checkbox 多选(max-h-60 滚动)+底部 border-t 新建输入(Enter 创建，随机取 8 色)。
6. **提醒**：SectionBlock(Clock)：每条 `group rounded-lg bg-muted/40 px-3 py-2 text-[13px]`(Bell+时间，点击弹 DateTimePicker 编辑=删旧建新；hover 显 X)+"添加提醒"文字按钮。
7. **关联任务**：SectionBlock(Link2)，relations.length>0 才渲染；徽章 `bg-accent text-[11px]` 关系类型（子任务/阻塞/被阻塞/关联/重复于/重复项）+ "任务 #{other_task_id}"。
8. **评论**：CommentList 卡片+相对时间+hover 删除+底部输入/Send。

数据流：打开时 `todoTaskGetDetail(id)` 五合一详情；每次变更后 loadDetail()+onTaskChanged()（父级 refetch）；删除走 useConfirmDelete(entityLabel="待办"，文案："删除待办"/"确定要删除「xxx」吗？此操作无法撤销。")。

### 3.6 表单 TaskFormSheet

包装通用 EntityFormSheet（side=right，w-full sm:max-w-md；分区标题带强调色竖条+渐变线；提交中 EqualizerLoader +"保存中…"；必填失败提示"请填写必填项：xxx"；提交文案 编辑="保存"/新建="创建"）。

| name | label | type | 备注 |
|---|---|---|---|
| title | 标题 | text | required，placeholder "输入任务标题" |
| description | 描述 | textarea | maxLength 5000 |
| project_id | 所属项目 | select | 默认当前选中项目 |
| priority | 优先级 | select | 无0/低1/中2/高3/紧急4/立即处理5，默认 0 |
| status | 状态 | select | pending/doing/done，默认 pending |
| due_date | 截止日期 | DatePicker | 提交时转毫秒时间戳 |
| start_date | 开始日期 | DatePicker | |
| hex_color | 颜色 | text | placeholder "#3B82F6"；⚖ 加正则校验 `^#[0-9a-fA-F]{6}$` |

### 3.7 右键菜单（⚖ 重写实现、保留全部条目）

蓝本是两套手写 fixed 定位 div（视口钳制/延时注册/子菜单 hover 展开），**重写为单一通用 ContextMenu 基元**（Radix DropdownMenu 的 context 触发模式），但菜单项集合与文案不变：

- 任务菜单：详情 / 完成 / 收藏 / 优先级▸(6档) / 标签▸ / 移动到项目▸ / 设置截止时间(Popover) / 设置提醒(Dialog) / 添加评论(Dialog, max-w-sm) / 删除(确认 AlertDialog)。
- 项目菜单：删除项目（destructive）。
- 视觉基线沿用蓝本：`min-w-[200px] rounded-md border bg-popover p-1 shadow-lg`。

### 3.8 标签管理器 LabelManager

Dialog(max-w-md)：标签列表 + **10 色预设色板** `#EF4444 #F59E0B #22C55E #3B82F6 #8B5CF6 #EC4899 #14B8A6 #F97316 #6366F1 #6B7280` 改色 + 增删；默认选中第 4 色(#3B82F6)。LabelAdder 新建随机色池：`#ef4444 #f97316 #eab308 #22c55e #06b6d4 #3b82f6 #8b5cf6 #ec4899`。

## 四、筛选 / 排序 / 搜索语义

- 搜索：匹配 title + description，不区分大小写。
- 状态筛选：all / undone(done==0) / pending / doing / done。
- 优先级筛选：all / 0..5 精确等于。
- 快捷视图：all / undone / done / today(due_date 在今日 0 点起 24h) / week(未来 7 天) / favorite(is_favorite==1)。
- 数据范围：项目精确 / 未分组(project_id IS NULL) / 隐藏 is_deleted==1（计数同样排除）。
- 排序（#26 双端档位，工具栏 Select，localStorage `todo_sort_key` 持久化）：`manual`(position 升序→created_at 降序，唯一允许拖拽重排的档位——列表行/看板卡拖拽、看板同列落位均仅该档生效)/`due`(无截止垫底→时间升序)/`priority`(大者前)/`title`(zh-Hans-CN)/`created`(降序)。**三视图归一**：sortTasks 结果直接决定列表序、看板列内序、日历按日分组内序（视图不再自行按 position 重排覆盖）；看板跨列移动（改归属）任何档位可用，落位走 position 中值。前端内存排序，一次拉取 page_size=10000 全量。

## 五、设计 Token

### 5.1 主题机制（整体平移 index.css + design-tokens.ts + color-theme.ts + theme.ts）
- Tailwind v4 `@theme inline`；全色 **OKLCH**；`@custom-variant dark (&:is(.dark *))`。
- 色板集：obsidian(264 蓝调·默认深) / deep-sea(220 青) / twilight(25 橙红) / emerald-night(162 绿) / daylight(亮) / custom（JS 派生，color-mix 半透明高亮）。切换 = `<html>` 上切 `data-palette` + `.dark` 类，custom 时 inline 注入 6 个变量；持久化 localStorage `color_palette`、`custom_palette_accent`、`theme_mode`（system 经 matchMedia 解析）；深色板统一 `color-scheme: dark`。
- obsidian 关键值：background oklch(0.16 0.01 264) / foreground oklch(0.96 0.01 264) / card·popover oklch(0.21 0.01 264) / primary oklch(0.62 0.19 264) / muted oklch(0.24 0.01 264) / muted-foreground oklch(0.68 0.02 264) / accent oklch(0.27 0.02 264) / border `oklch(1 0 0 / 10%)` / input `/15%` / sidebar 系列 0.18/0.24；daylight 对应亮色值从蓝本平移。
- 圆角：`--radius: 0.625rem`，派生 sm 6 / md 8 / lg 10 / xl 14px。
- 动效时长 token：instant 100ms / fast 150ms / base 200ms / slow 300ms（Sheet=slow，Dialog/Popover/Select=base，hover=fast/instant）；页面过渡 `.page-transition`（opacity 0→1 + translateY 6px→0, ease-out）。
- 字体：system-ui 栈；可配置族(--app-font-family)/字号级别(root 0.875×–1.375×)/字重 300–700；keys：font_family/font_size_level/font_weight_level。
- **Mica 配方**（Win）：html/body background transparent + Tauri Mica（亮开暗关）；TitleBar 与 Sidebar 与 main 均 `bg-background/60 dark:bg-background/85`；Card 基座 `bg-card/60 dark:bg-card/85 backdrop-blur-sm rounded-xl border shadow-sm`。macOS 用 vibrancy 替代，Linux 降级纯色。
- todo 模块强调色硬编码 `#3B82F6`（默认项目色/看板项目列头/"全部任务"图标），不走 cfg 动态读取。

## 七、⚖ 不一致点规范化决策（复刻时执行）

| # | 蓝本现状 | 决策 |
|---|---|---|
| ① | 右键菜单"设置提醒"用原生 datetime-local，详情抽屉用自有 DateTimePicker | 统一用自有 DateTimePicker |
| ② | hex_color 是纯文本输入 | MVP 保留文本 + 正则校验；色板控件记 M6+ |
| ③ | 命令面板跳 `/todo/:uuid` 但路由不存在（死链） | 新增轻量 zustand `selectedTaskId`：命令面板点击任务 → 导航 `/todo` 并打开详情抽屉；不做 :id 路由 |
| ④ | projects/labels 在 list 页绕过 react-query（useState+直接 invoke） | 收编 react-query（queryKey `["todo-project","list"]` / `["todo-label","list"]`，变更 invalidate）；其余 refetch 回调模式保持 |
| ⑤ | 看板卡片无标签/子任务进度展示 | 保持蓝本现状 |

localStorage 键全集：`todo_view_mode` · `todo_sidebar_ungrouped_after` · `color_palette` · `custom_palette_accent` · `theme_mode` · `font_family/font_size_level/font_weight_level`。（弃用 `my_nav_items`）
