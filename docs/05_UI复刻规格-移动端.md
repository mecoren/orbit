## 三、"液态玻璃"三件套（复刻成败核心）

任何玻璃表面必须同时具备：**① backdrop blur + ② 半透明 tint 底 + ③ 1px 五段高光线**，缺一即不成立。

| 使用处 | blur(σ≈CSS px 1:1) | tint | 高光线位置 |
|---|---|---|---|
| LiquidGlassTitleBar | `blur(20px)` | 同上 | 底边缘 |
| GlassFab（⏸ 底部导航属 M6+，规格备用） | `blur(18px)` | 同上 | 内侧底部 |
| 表单日期字段盒 | `blur(10px)` | surface@50% | — |
| 卡片/弹层上限 blurStatic | ≤ `blur(45px)` | — | — |

高光线：`height:1px` 水平渐变五段 alpha——亮色 `[0,.85,1,.85,0]`、暗色 `[0,.30,.45,.30,0]`。
无级渐变模糊（标题栏顶强底弱）：上层伪元素完整 blur+tint，用 `-webkit-mask-image` 垂直渐变做 alpha 遮罩；Safari/WKWebView mask 失效时降级为分段 blur + 渐变蒙版 div。**滚动 offset=0 时必须移除模糊层**（性能与观感双要求）。
性能纪律：滚动偏移存 ref 直接改 style.opacity，模糊层独立 memo 组件（对应蓝本 RepaintBoundary/ValueListenable 优化），禁止整页 setState。

## 四、逐屏规格

### 4.1 侧栏首屏 `/todo`

- 标题栏：LiquidGlassTitleBar 单行模式（showSecondRow=false），title "待办"，右侧 actions 仅搜索钮（Material Symbols `search_rounded`）→ push `/todo/tasks?view=all`。**左端云同步状态图标**（`sync_status_button.dart`，经 `LiquidGlassTitleBar.leading` 插槽：同步中转环 / 成功对勾回弹 1.8s / 失败红点常驻；移动端无 hover，点击弹底部信息面板 = 状态 + 上次同步 + 下次自动同步估算 + 失败原因 + 「立即同步」；未配置 / 未解锁 → push `/settings/sync`）。
- 主体 CustomScrollView 三段：
  1. **快捷视图**：SectionHeader("快捷视图") + 6 个 ListTile 行——leading icon size22 用 quickView 语义色、title 16/w500 onSurface、trailing `chevron_right_rounded`(onSurfaceVariant)。图标映射：全部任务 `list_alt_rounded` / 未完成 `radio_button_unchecked_rounded` / 已完成 `check_circle_outline_rounded` / 今天截止 `calendar_today_rounded` / 本周截止 `date_range_rounded` / 收藏 `star_border_rounded`。点击 → `/todo/tasks?view=<name>`。
  2. **项目**：SectionHeader("项目", trailing=`add_rounded`(22, compact)) + 可拖拽重排列表。行结构：12×12 圆角方块(hex_color||强调色) + 名称 16/w500 + 尾部[未完成计数 badge(surfaceContainerHighest 底、radius 8、padding h8/v2、字12，仅 >0 显示) + gap8 + `drag_handle_rounded`(onSurfaceVariant@50%)]. 长按 = 删除流程；拖拽代理底色 surfaceContainerHighest。排序落库逐条 `sortOrder=i+1`，本地覆盖列表先行渲染，失败 toast"排序失败"(destructive)。
  3. **未分组**：`inbox_rounded`(22, onSurfaceVariant) + "未分组" 16/w500 + 同款计数 badge + chevron。
- 新建项目对话框：AlertDialog "新建项目" + WaitInputField(label 项目名称, autofocus) + 取消 TextButton / 创建 FilledButton；创建默认 `#3B82F6`；成功 toast"已创建/项目已创建"。
- 删除保护：有未完成任务 → AlertDialog"无法删除"/"该项目下还有 N 条未完成任务，请先清空或移走任务后再删除。"/按钮"我知道了"；否则 WaitAlertDialog(destructive)"删除项目"/"确定要删除项目「x」吗？该操作不可撤销。"。
- SectionHeader 规格：padding L16/R8/T12/B4，labelMedium、onSurfaceVariant、w600。
- 列表底部预留 space48。

### 4.2 任务子列表 `/todo/tasks`

- 标准 AppBar：返回 `arrow_back_rounded` + 动态标题（项目名/"未分组"/视图名）+ 右上 `more_vert_rounded`（MVP 无动作）。
- 列表：ListView padding top8/bottom48，每项 TodoTaskTile（§4.5）。
- 空态 EmptyState(icon=`checklist_outlined`)，文案按入口：暂无任务 / 暂无未完成任务 / 暂无已完成任务 / 今天没有截止的任务 / 本周没有截止的任务 / 暂无收藏任务 / 该项目暂无任务 / 暂无未分组任务。
- FAB：AboveBottomNavFab(extraMargin=4) 包 GlassFab(**accentColor=全局 themeAccent**)，点击弹新建表单抽屉（携带 defaultProjectId）。
- 过滤语义照抄：today=自然日相等；week=today ≤ d < today+7；勾选完成写 `status=pending|done`；星标写 `is_favorite`。

## 六、Flutter→CSS 换算速查

```
ImageFilter.blur(σ) ≈ backdrop-filter: blur(<σ>px)   // 高斯标准差语义一致，1:1
withValues(alpha:)  → rgba()/color-mix()
MediaQuery.padding  → env(safe-area-inset-*)
SilkyScrollPhysics  → MVP 接受 WebView 原生滚动（保留 overscroll-behavior；
                      Q 弹停止需接管滚动物理，成本高，记 M6+）
长按                → pointerdown 起 500ms 定时器 + contextmenu preventDefault
```

## 八、与桌面端有意不对称（2026-09-19 第六轮 D5）

- 桌面端写路径已乐观化（`lib/query-patch.ts` + `task-actions.ts` + `batch-actions.ts`：
  先 patch 缓存提前 paint，db-change 失效链收敛），移动端**明确不做乐观对齐**：
  Riverpod 侧是 `invalidateBusinessCaches` 统一失效模型，与 React Query 的
  按 key patch 不对构，另立项再议。
