## 三、触控适配（补齐时遵守并已落实）

对齐**不改核心逻辑**，仅按移动端触控特性落地：

1. 桌面右键菜单 / Dialog → 移动**底部抽屉**（`showMoreActionsSheet` / `showSelectBottomSheet` /
   `OrbitSheetScaffold`），符合 AGENTS.md「选择类/确认类交互统一底部抽屉」口径。
2. 表单新增字段遵循「区块 + 点行弹抽屉」二段式，行高 ≥ `AppDimens.touchTarget`。
3. 不引入桌面专有手势（hover、右键、Ctrl 快捷键）；多选、拖拽、长按沿用既有触控语义。
4. 主题 token 一律取 `core/theme`（`AppColors`/`AppDimens`/`AppShapes`/`OrbitAccents`），
   不写裸魔法值；复用现有 `orbit_*` 原语，未新增一次性样式。

## 六、兼容性说明

- **零协议面**：未动 DDL、未动 `sync_registry.rs` 同步白名单、未动 FRB 桥签名
  （全部走既有桥方法），云端数据格式与同步语义零变化。
- **存量库**：无迁移，老库直接可用。
- **触控适配**：桌面右键/Dialog 全部映射为底部抽屉或面板条目，符合移动端
  「选择类/确认类统一抽屉」口径；行高 ≥ `AppDimens.touchTarget`；
  长按菜单加长后（13 项）内容区自滚，`_ActionsSheet` 已支持滚动。
- **平台**：iOS / Android 通用（无平台特有 API）。
- **有意边界**（维持 docs/05 §九 / docs/10 §八）：不做「滑到底直接完成」、不做底部 Tab
  改版、不做协作/番茄钟/习惯等生活记录域模块。
