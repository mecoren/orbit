# 需求文档：桌面端工具栏收拢——右上角「排序 ↑↓」+「更多 ···」双菜单

## 一、需求理解

桌面端任务面板工具栏右侧现有 12 个控件（搜索框、状态 Select、隐藏已完成、存为视图、优先级 Select、排序 Select、视图五联钮、看板分组 Select、Ctrl+P 钮、标签管理钮、新增、模板），拥挤且低频项占据常驻位。参照 TickTick Web 端（参考图 1/2），在工具栏右上角新增两个按钮，把低频/次高频功能收拢进菜单：

- **「↑↓」排序菜单**（图 2）：`分组 >`、`排序 >`、`顺序（从旧到新/从新到旧）>` 三行，子菜单就地展开。
- **「···」更多菜单**（图 1）：隐藏已完成 + 存为视图 + 搜索或跳转 + 标签管理。
- **视图切换单钮**（2026-10-30 追加）：钮面 = 当前视图图标，下拉五档单选（详见第五节）。

## 二、功能需求

1. 工具栏新增三个 icon 按钮（h-8 w-8，与现工具栏同规格）：视图切换（钮面图标随当前视图变化）、`ArrowUpDown`（排序）、`Ellipsis`（更多），位于搜索框右侧、新增按钮左侧，带 Tooltip。
2. 「↑↓」菜单：
   - **分组**：子菜单 = 按项目/按状态；仅看板视图下显示该行（与现条件一致）。
   - **排序**：子菜单 = 拖拽顺序/截止时间/优先级/标题/创建时间（现五档全量）。
   - **顺序**：升序/降序两档；`manual`（拖拽顺序）档下该行隐藏（拖拽序无方向概念）。
3. 「···」菜单：
   - **视图**：2026-10-30 起上提为工具栏「切换视图」单钮（钮面图标 = 当前视图，下拉五档单选），不再是菜单内图标排。
   - **状态**：子菜单 = 全部/未完成/待办/进行中/已完成（现五档）。
   - **优先级**：子菜单 = 全部/无/低/中/高/紧急/立即处理（现七档）。
   - **隐藏已完成**：可勾选菜单项，置灰条件与现状一致（Logbook 视图 / 已完成状态筛选下禁用）。
   - **存为视图**：菜单项，行为与现按钮一致（当前工具栏筛选预填构建器）。
   - **搜索或跳转**：菜单项（Ctrl+P 快捷键不变）。
   - **标签管理**：菜单项，打开既有 LabelManager 弹窗。
4. **从工具栏移除**（收拢后）：状态 Select、隐藏已完成钮、存为视图钮、优先级 Select、排序 Select、视图五联钮、看板分组 Select、Ctrl+P 钮、标签管理钮——共 9 个控件。
5. **保留在外**：搜索框、视图切换单钮、「↑↓」、「···」、新增、模板下拉、完成进度线（底缘装饰）。
6. 新增排序方向持久化：localStorage 键 `todo_sort_dir`（遵循 04 §七命名风格）；首次未存过时各排序档保持现状默认方向，不改变既有用户可见顺序。
7. 菜单交互：子菜单就地展开（Radix DropdownMenuSub）；全部档位变更即时生效；菜单内当前档位带勾选态。

## 三、验收标准

- 工具栏右侧仅剩：搜索框、视图、↑↓、···、新增、模板（≤6 控件 + 进度线；2026-10-30 视图入口上提后由 5 变 6）。
- 「↑↓」切排序档/方向、「···」切视图/筛选/隐藏完成后，列表行为与收拢前逐项等价（数据语义零变化，纯入口搬家）。
- 刷新后排序档位、方向、视图模式、隐藏已完成状态从 localStorage 恢复（沿用既有键 + 新增 `todo_sort_dir`）。
- 键盘链路不断：Ctrl+P 命令面板可从菜单项与全局快捷键两处打开。
- e2e 全量绿（既有用例改走菜单路径：隐藏已完成/存为视图/标签管理；切视图走「切换视图」单钮）；新增用例覆盖「↑↓」切排序方向 + 「切换视图」五档往返。

## 四、变更记录

- **2026-10-30 视图入口上提**：原「···」菜单顶栏的五联图标排（列表/看板/日历/表格/矩阵，点按即切不关菜单）替换为工具栏独立「切换视图」单钮（钮面图标 = 当前视图，下拉五档单选）。动因：切视图是高频主操作，藏在两级菜单里要多一次点击，且菜单弹层遮住列表，切完还得再收一次；但五钮全平铺会把工具栏控件从 5 推到 10，与本文档的收敛目标相反，故取「一钮一档」中间态。菜单因此回到纯低频入口。e2e 的 `switchViewViaMenu` 辅助函数同步改为 `switchView`（点钮 → 点 `menuitemradio`，radio 选中即收菜单）。
