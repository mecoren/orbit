# 需求文档：移动端新建/编辑待办表单全量对齐桌面端

## 一、需求理解

移动端「添加待办」底部抽屉目前仅有 标题/描述/项目/优先级/截止日期 五个字段；需要补齐桌面端表单的全部字段与语义（提醒时间、重复规则、状态、开始/结束日期、颜色），使两端创建的数据口径一致。

## 二、桌面端参照（apps/desktop/src/features/todo/desktop/task-form-sheet.tsx）

| 字段 | 桌面端形态 | 语义 |
|---|---|---|
| title | 文本，必填 | trim 后提交 |
| description | 多行文本，上限 5000 | 空转 null |
| project_id | 下拉（未分组/项目列表） | 空串转 null |
| priority | 下拉 0–5（无/低/中/高/紧急/立即处理） | 数字 |
| status | 下拉（pending/doing/done） | 字符串，默认 pending |
| due_date / start_date / end_date | 日期选择 | 提交转当日零点毫秒时间戳，空转 null |
| remind_at（虚拟字段） | 日期时间选择 | 非任务列：新建→建任务后 todoReminderCreate；编辑→「清空删 / 变更删旧建新 / 未动跳过」 |
| hex_color | 文本 + 正则 `^#[0-9a-fA-F]{6}$` | 非法拦截保存；空/未填跳过 |
| 重复规则 repeat_mode/repeat_after | 桌面在详情抽屉编辑 | mode：0 不重复/1 天/2 周/3 月/4 年；after=间隔数 ≥1；预设 每天/每周/每月/每年，自定义走 天×N |

## 三、功能需求

1. 移动端表单新增字段，顺序对齐桌面端：状态（截止日期前）、开始日期、结束日期（截止日期后）、提醒时间、重复规则、颜色（表单尾部）。
2. 提醒时间：点按打开 日期 → 时间 双选择器；已设置可清除；提交语义与桌面端一致（删旧建新）。
3. 重复规则：不重复/每天/每周/每月/每年 + 自定义（间隔数 N × 单位 天/周/月/年）。
4. 状态：待办/进行中/已完成 三档，默认待办。
5. 颜色：#RRGGBB 文本 + 正则校验，非法时不允许保存。
6. 编辑态：全字段回填（提醒取该任务第一条未删除提醒）。
7. 保存成功后失效 todoTasksProvider / taskDetailProvider（既有行为保持）。

## 四、验收标准

- 一级页面 FAB 与二级页面 FAB 打开的表单均含全部新字段。
- 新建：填写提醒时间并保存 → todoReminderList 出现该任务提醒；选择「每天」→ 落库 repeat_mode=1、repeat_after=1。
- 编辑：修改提醒时间 → 旧提醒被删、新提醒建立；清空 → 提醒被删。
- 颜色输入非法值 → 校验拦截，抽屉不关闭。
- 既有 38 个测试不回归；新增测试覆盖上述场景。
